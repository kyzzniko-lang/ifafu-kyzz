常见问题

这是官方应用吗？

iFAFU 是面向福建农林大学学生的开源校园助手项目，与学校官方教务系统相互独立。

账号密码会被保存吗？

登录信息仅保存在你的设备本地，不会上传到本介绍页服务器。

下载后无法安装怎么办？

请确认设备为 Android 系统，并在系统设置中允许浏览器安装未知来源应用。

如何反馈问题？

可以在应用内提交意见，也可以前往 GitHub 查看源码、提交 Issue。
