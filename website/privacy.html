PRIVACY & SECURITY

隐私与安全

账号信息

iFAFU 使用教务系统账号登录。账号信息主要保存在用户设备本地，用于访问学校教务系统，不会上传到本介绍页服务器。

AI 功能（宠物聊天 / 笔记智能分类）

AI 对话功能由第三方大模型服务提供。自 v2.5.9 起，模型请求经由项目自建的代理服务器转发：模型 API 密钥只保存在服务器端，不会打包进 App。为生成个性化回复，对话请求中会包含与你学业数据相关的上下文（如课表、考试、成绩概况）；代理服务器仅做转发与限流，不记录任何对话内容。若不希望上述数据参与 AI 功能，可以不使用宠物聊天与 AI 分类功能，其余功能不受影响。

反馈与讨论

当用户主动提交意见、校园讨论或课程评价时，提交内容会发送到项目的反馈服务，用于展示或处理问题。请不要在公开内容中填写身份证号、手机号、密码等敏感信息。

开源与反馈

项目源码公开在 GitHub。用户可以通过应用内反馈或 GitHub Issue 提交建议和问题。

安全提醒

请只从本页面或项目官方发布渠道下载 APK。安装前检查应用来源和版本信息，不要安装来源不明的修改版安装包。
